# Farooq Portfolio

Static site: plain HTML pages (`index`, `about`, `projects`, `services`, `contact`), one stylesheet (`assets/css/styles.css`) and one script (`assets/js/main.js`). No build step; preview with `python3 -m http.server 8000`.

## Design references

Brand design systems live at `design-md/awesome-design-md/design-md/<brand>/DESIGN.md` (for example `design-md/awesome-design-md/design-md/airtable`). When asked to design in the style of a brand, read that brand's folder.
